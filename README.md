# Pandas

A friendly study repository for learning **Python Pandas**.  
Every topic includes simple explanations, comments, and runnable examples.

## What is Pandas?

Pandas is a Python library used to work with structured data, such as tables, CSV files, and Excel sheets.
Its two main data structures are:

- **Series**: a one-dimensional labelled list.
- **DataFrame**: a two-dimensional table with rows and columns.

## Topics covered

1. Installing and importing Pandas
2. Series and DataFrames
3. Reading and writing CSV files
4. Exploring data (`head`, `tail`, `info`, `describe`, `shape`, `value`)
5. Selecting rows and columns (`[]`, `loc`, `iloc`)
6. Filtering data
7. Adding, updating, and deleting columns
8. Missing values
9. Sorting
10. Grouping and aggregation
11. Combining tables (`concat`, `merge`)
12. Renaming columns and changing data types
13. Removing duplicate rows
14. Basic date handling
15. Exporting data

## Setup

Install Python, then open a terminal in this project folder and run:

```bash
python -m pip install -r requirements.txt
```

Run the examples:

```bash
python pandas.py
```

The script creates a small sample dataset in memory, so you do not need to download a dataset first.

## Suggested learning method

- Read one section at a time.
- Run the code yourself.
- Change values and observe what happens.
- Try the practice tasks at the bottom of `pandas.py`.
